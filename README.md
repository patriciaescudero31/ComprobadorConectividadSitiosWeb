# Proyectos-python

Colección de proyectos personales en Python.

Proyectos destacados
- comprobador_conectividad_sitiosweb.py  
  Script original que abre una ventana Tkinter para comprobar el código HTTP de una URL.
- comprobador_conectividad_sitiosweb_mejorado.py  
  Versión mejorada no bloqueante: normaliza la URL, maneja errores explícitos, usa timeout y ejecuta la comprobación en un hilo para que la GUI no se congele.

Cómo ejecutar
1. Clona el repositorio (si aún no lo has hecho):
   git clone https://github.com/patriciaescudero31/Proyectos-python.git
   cd Proyectos-python

2. Ejecuta el script (Python 3):
   python comprobador_conectividad_sitiosweb.py
   o
   python comprobador_conectividad_sitiosweb_mejorado.py

Nota: en algunas distribuciones Linux puede ser necesario instalar tkinter:
   sudo apt install python3-tk
